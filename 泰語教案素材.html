📊 數字應用

G0-1: 數字

句型結構: ที่ + ตัวเลข (ที่+數字 → 第幾)
編號 泰文 拼音 中文 拆解
十 สิบ sìp 十 -
三十 สามสิบ sǎam-sìp 三十 สาม(三) + สิบ(十)
百 ร้อย róoi 百 -
一百 หนึ่งร้อย nèung-róoi 一百 หนึ่ง(一) + ร้อย(百)
千 พัน phan 千 -
二千 สองพัน sǒong-phan 二千 สอง(二) + พัน(千)
萬 หมื่น mùen 萬 -
三萬 สามหมื่น sǎam-mùen 三萬 สาม(三) + หมื่น(萬)
十萬 แสน sǎen 十萬 -
五十萬 ห้าแสน hâa-sǎen 五十萬 ห้า(五) + แสน(十萬)

G0-2: ที่ + 數字 (第…)

句型結構: ที่ + ตัวเลข (ที่+數字 → 第幾)
編號 泰文 拼音 中文 拆解
1 ที่ หนึ่ง thîi-nèung 第一 ที่(第) + หนึ่ง(一)
2 ที่ สอง thîi-sǒong 第二 ที่(第) + สอง(二)
3 ที่ สาม thîi-sǎam 第三 ที่(第) + สาม(三)
21 ที่ ยี่สิบเอ็ด thîi yîi-sìp-èt 第二十一 ที่(第) + ยี่สิบเอ็ด(二十一)

G1: 量詞 + ที่ + 數字 (第…年/天/人)

句型結構: ลักษณนาม + ที่ + ตัวเลข (量詞+ที่+數字 → 第幾+量詞)
泰文 拼音 中文 拆解
ปี ที่ หนึ่ง bpii-thîi-nèung 第一年 ปี(年) + ที่(第) + หนึ่ง(一)
อัน ที่ สอง an-thîi-sǒong 第二個 อัน(個) + ที่(第) + สอง(二)
วัน ที่ สาม wan-thîi-sǎam 第三天 วัน(天) + ที่(第) + สาม(三)
คน ที่ สี่ khon-thîi-sìi 第四個人 คน(人) + ที่(第) + สี่(四)
แก้ว ที่ ห้า gâeo-thîi-hâa 第五杯 แก้ว(杯) + ที่(第) + ห้า(五)
จาน ที่ หก jaan-thîi-hòk 第六盤 จาน(盤) + ที่(第) + หก(六)
เดือน ที่ เท่าไหร่ duean-thîi-thâo-rài? 第幾個月? เดือน(月) + ที่(第) + เท่าไหร่(幾)
อัน ที่ แปด an-thîi-bpàet 第八個 อัน(個) + ที่(第) + แปด(八)

📝 文法句型

G5: 是…對嗎? (ใช่ไหม?)

句型結構: N. + เป็น/คือ + N. + ใช่ไหม + ครับ?
泰文 拼音 中文
คุณ เป็น คนไทย ใช่ไหม ครับ khun bpen khon-thai châi-mǎi khráp? 你是泰國人,對嗎?
นี่ เป็น ร้านอาหาร ใช่ไหม ครับ nîi bpen ráan-aa-hǎan châi-mǎi khráp? 這裡是餐廳,對嗎?
คุณ เป็น คนจีน ใช่ไหม ครับ khun bpen khon-jiin châi-mǎi khráp? 你是中國人,對嗎?
เขา เป็น หมอ ใช่ไหม ครับ khǎo bpen mǒo châi-mǎi khráp? 他是醫生,對嗎?
นั่น เป็น รถของคุณ ใช่ไหม ครับ nân bpen rót-khǒong-khun châi-mǎi khráp? 那是你的車,對嗎?
นั่น คือ ต้มยำกุ้ง ใช่ไหม ครับ nân khue dtôm-yam-gûng châi-mǎi khráp? 那是泰式酸辣蝦湯,對嗎?
นั่น คือ ร้านสะดวกซื้อ ใช่ไหม ครับ nân khue ráan-sà-dùak-súue châi-mǎi khráp? 那是便利商店,對嗎?
นี่ คือ มือถือของคุณ ใช่ไหม ครับ nîi khue mue-thǔe-khǒong-khun châi-mǎi khráp? 這是你的手機,對嗎?
นี่ คือ เมนูภาษาไทย ใช่ไหม ครับ nîi khue mee-nuu-phaa-sǎa-thai châi-mǎi khráp? 這是泰文菜單,對嗎?
